# Werkelijk Rendement 0.1.0 — desktop beta

Download the Windows ZIP, Linux AppImage, or Linux portable archive below.
Each download includes a separate SHA-256 checksum. Python and separate PDF
extraction tools are not required.

- Automatic folder discovery and deterministic parsing of supported financial PDFs.
- Local Streamlit dashboard with Dutch/English controls, fiscal-partner and child profiles.
- Transparent account breakdown, explicit missing-data states, and audit ZIP exports.
- Direct browser launch, native folder selection, import progress and cancellation.
- Shared PDFium extraction for CLI and desktop, with versioned import refresh.
- Persistent per-user data, loopback-only services, and no usage telemetry.

Document processing stays entirely on your computer. Nothing is uploaded or
parsed by an LLM, and original documents are not modified.

This is a beta for Windows 10/11 x64 and Linux x86-64 with glibc 2.35 or newer.
The Windows executable is unsigned. Only documented statement layouts and tax
comparison policies for 2017–2025 are supported; check coverage and original
evidence before relying on a result. Completing an import does not prove that
all assets or partner documents are present.

See the documentation included in the archive for launch instructions and known
limitations. Close the running application before launching an updated binary;
scan your saved document folder when asked to refresh older imports.
